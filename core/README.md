# Core: shared by every console

Parts of the NZEUS system that are the same on every console. A console's port
(`../ports/<console>/`) copies them into its system image.

| Folder | What it is |
|---|---|
| [`deck-modern/`](deck-modern/README.md) | The helper programs the Deck calls: Wi-Fi join, Bluetooth, updates, WhatsApp, the web reader |

See [../ports/README.md](../ports/README.md) for how shared parts and ports fit together.

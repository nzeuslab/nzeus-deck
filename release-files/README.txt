NZEUS Deck - Linux 7.2 + Debian 12 for the R36S V2.7 clone (HiChip E3100)
==========================================================================

ONLY for the R36S V2.7 with the HiChip E3100 chip (board HC16E3100V20), any colour.
Most R36S consoles use a Rockchip chip: this is NOT for them.
Tested on real consoles.

Install (Windows):  console's SD card in a card reader -> double-click install.bat
On a NEW SD card:   double-click install-new-card.bat (the original card is only read)
Undo (Windows):     double-click uninstall.bat
Bug report logs:    double-click collect-logs.bat
Mac / Linux:        see more\INSTALL.md

Your games stay on the card, unless it is too full: then install.bat asks
whether to delete the games to make room. The console's flash chip is never written, so
uninstall.bat always brings the console's own system back.

This is a research project from NZEUS LAB, not a product: use it at your own
risk. Source code, write-up and issue tracker: see more\SOURCE.txt.
